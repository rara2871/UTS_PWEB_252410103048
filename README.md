# Deskripsi Website:
Website panduan resep masakan Genshin Impact yang dibangun menggunakan Laravel murni dengan arsitektur MVC tanpa database dan tanpa starter kit. Memiliki fitur simulasi login yang meneruskan username ke Dashboard dan Profil, serta menampilkan katalog resep makanan Teyvat dari Controller menggunakan perulangan Blade.
